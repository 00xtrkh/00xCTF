**00xCTF** is a modern web platform for CTF (Capture The Flag) competitions, built with React and Spring Boot.
Users and teams can solve challenges in categories like Web, Crypto, and Forensics.
The platform has a live scoreboard, flag submissions, hints, and an admin panel to manage challenges.
It is made for learning, practicing, and competing in cybersecurity, and it is safe, easy to use, and easy to improve.
